# Canvas Car Game

An arcade inspired game made with JS and HTML canvas, playable within a web browser.

## Playing

The player car can be controlled with WASD or arrow keys. Earn score by avoiding traffic and not crashing.

You can play the game on my [GitHub Pages](https://dmfcat.github.io/canvas-car-game/).

## Running Locally

1. Download or clone this repo.

```bash
git clone https://github.com/dmfcat/canvas-car-game
```

2. Open `index.html` in your web browser of choice.
